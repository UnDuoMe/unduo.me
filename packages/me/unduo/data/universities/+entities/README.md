# @-/me.unduo.data.universities.entities

Public metadata type for the university directory, detached from the catalog. Import `University` from this package. Enrollment URLs are optional and must be backed by university documentation. `duoPrompt: "universal"` marks a portal that uses Duo's Universal Prompt, whose setup file names its labels (Add a device → Duo Mobile → I have a tablet → Next) instead of the Traditional Prompt's My Settings & Devices.
