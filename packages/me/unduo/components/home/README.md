# @-/me.unduo.components.home

The website's home page. `startHomePage()` builds it in the page's `#root` as a landing page. Its hero fills most of the first screen, centered: the name, a one-line description, "UnDuo is a secure, single file that you can audit and use locally.", and a card holding "Select your university below to get started:" and a searchable dropdown (placeholder "Search for your university...", label "Select Your University"), with a footer at the bottom: contact@unduo.me as an email link (`mailto:`), and GitHub, with its mark, linking to the source. Typing in the field filters the institutions under it, and choosing one with Enter or a click opens a modal dialog for it that shows one step at a time, with Back from step 2 on. Escape, the close button and Done on the last step close it, and focus returns to the field. It has no stepper; the institution's setup file keeps its own.

Under the hero (`home-landing.ts`):

- **Fully safe, but don't take our word for it.**: the user's heading and lead (you can audit UnDuo with all the major AIs: ChatGPT, Claude, and Gemini; all three classify it as fully safe), then a carousel that shows one AI at a time, with arrows that wrap around, a button per AI and a sideways swipe; the slides out of view are `inert`. Each slide has its strongest model and its verdict ("Safe: yes") beside a screenshot of the conversation, which sits on the left from 960 px up and on top below that: the setup file, saved as `UnDuo - Other.html` so it names no school, and the prompt above the reply, which opens larger in a dialog. Beside it is the whole reply, from `aiReplies` in `ai-replies.ts`, as Markdown that `replyText()` turns into paragraphs, headings, lists and bold, all text nodes. It's shown whole, nothing cut off, so its end, where the prompt's P.S. asks for the file's SHA-256 hash, is in view; the screenshot is shown whole too. The screenshots are `ai-reply-<id>.webp` in `apps/unduo-web/src/assets/`, taken by `vp run capture:ai` ([`configs/ai-replies`](../../configs/ai-replies)): each is a single screenshot of the whole conversation, the prompt unfolded, zoomed out until it fits, nothing joined. The build publishes them with the other assets and `homeMount()` (the `./server` entry) puts them in an `#ai-reply-images` template with their SHA-256; `showScreenshot()` fetches each only if its hash matches and shows it as a blob: URL, as the setup file does with its screenshots.
- "Think the screenshots might be fake? You can **check for yourself.**": a button drawn as a link that saves `UnDuo - Other.html` and opens **Other**'s dialog at **Copy prompt**. Closing the dialog returns focus to the button, so the page stays where it was.
- **How UnDuo Works**: the three steps, stacked as cards in the layout of Discord's landing page: an illustration on one side (alternating sides from 960 px up, above the text below that) and, on the other, "Step N", the step's line as a heading and a short description. The illustrations, in `how-art.ts`, are inline SVG drawn with `rect`, `path` and `svgText` from `@-/me.unduo.lib.dom`, hidden from screen readers, so the page fetches nothing for them; their QR codes are drawings that encode nothing.
- **Get Started**, a button at the bottom, under the bold call to action "Ready to replace Duo with a secure 2FA app?", that jumps straight back up to the search, without smooth scrolling, focuses it and opens its list.

1. **Download**: three lines: "Click the link below to download UnDuo's secure webpage, `UnDuo - <institution name>.html` (a file badge), _but don't open it yet:_", then the link, whose text is the file's name, underlined, which saves it from `./files/<WHED number>` (`./files/other` for **Other**, as `UnDuo - Other.html`), then "Next, we'll show you how to verify it's safe to use." Beside it, a drawing (`downloadArt()`) shows a click on the download button and the browser's Downloads panel popping up under its button with the file.
2. **Copy prompt**: "The prompt below validates that `UnDuo - <institution name>.html` is safe to use.", the prompt, and **Copy prompt to clipboard** (a clipboard icon), the step's main action. Beside it, a drawing (`copyArt()`) shows the copy landing on a clipboard.
3. **Verify**: a tab group picks the AI (ChatGPT, selected first, Claude, Gemini or Other), and a drawing beside the text shows a browser with its Downloads panel open over that AI's start page, the file dragged into its message box (`dragArt()`). The text reads "Open <AI> in a new window, press your browser's download button, then drag `<file>` into <AI> and paste in the prompt you copied." Its **Open <AI>** link (an arrow-out-of-a-box icon) opens the AI with `window.open()` as a popup window over the right of this one (`openWindow`), so the steps stay in view; modified clicks and blocked popups follow the link to a new tab. Under it: "If that button doesn't work, press ⌘N (Ctrl+N off Apple devices) to open a new window and type _<the AI's host>_ into the address bar." Other has no link: it says to press ⌘N, type your AI's address, then press the download button and drag the file in.
4. **Continue**: "Open your Downloads and double click the `UnDuo - <institution>.html` file to open UnDuo's secure webpage." (the name a file badge), then "Follow the webpage's instructions to set up a new 2FA app for <institution name>." ("your organization" for **Other**), then, in italics, "**Remember:** Never trust any website with your sensitive school login credentials without a way for you to verify it's 100% safe. Stay safe out there!" The file has its own stepper from there. Beside it, a drawing (`openArt()`) shows a double click on the file in the Downloads panel opening it in a window of its own. Every step's drawing is inline SVG in `how-art.ts`, animated unless motion is reduced, and the dialog widens to 56rem from 900 px to fit it beside the text.

`?university=` holds the institution whose dialog is open, as an id or an unambiguous name, and `#step=` the step, so Back, Forward, reload and shared links work. A link with an institution but no step opens the download step, and closing the dialog drops both from the address. An unpublished institution opens no dialog. Step names from earlier versions of the page (`university`, `overview`, `check`, `open`, `safe`) still lead to their new steps.

The prompt, `aiPrompt` in `ai-prompt.ts`, lives in this page's script, which the file doesn't contain, so the file an AI reads doesn't hold the question put to that AI. A test enforces that. It touches no DOM, so the package's `./server` entry exports it for scripts: `configs/ai-replies` asks ChatGPT, Gemini and Claude the same question and records their replies with screenshots.

The page's stylesheet, `home-styles.css` (the `./styles.css` entry), imports the setup files' stylesheet and adds the rules only this page uses. The build publishes it and the page's images in their own assets commit, apart from the setup files', so a change here never changes a setup file or its SHA-256, which the AI cards show.
