# @-/me.unduo.components.setup.limits

The setup page's **Advanced** panel for the setup plugin's resource limits. `pluginLimits(page)` builds a `<details>` toggle with fields bound to the setup page's `limits` and a button that calls `restart`, which loads a fresh plugin with those limits and starts setup over. The fields are the plugin's memory pages (64 KiB each), which cap each call's input and output and the module's own memory, and the per-call time limit that the plugin guard enforces. The hints show `defaultPluginLimits` from `@-/me.unduo.components.setup.plugin`. The button stays disabled while a field is empty or below 1; `loadSetupPlugin` refuses anything else that isn't a positive whole number, which shows the page's error until the limits are fixed. It is not a `<form>`, so the only form on the page is still the Duo request.
