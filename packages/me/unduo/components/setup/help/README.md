# @-/me.unduo.components.setup.help

Help, privacy and terminal dialogs as native popovers: a `popovertarget` button opens each one, and the close buttons, Escape and clicking outside close it, with no code of ours. `setupHelpButton("guide")`, `"privacy"` or `"terminal"` builds the button and its dialog with VanJS. The terminal dialog shows `terminalCommands` from the root API, which the repository README repeats and `__tests__` runs against a local stand-in for Duo.
