# @-/me.unduo.components.setup.portal

Duo device portal guidance and example enrollment screenshots. `portalStep(school, page)` builds the step with the institution's portal link, note and source, which the page's `#setup` element holds as data attributes, then "Press **Continue** when you see a page like this:" over two examples of Duo once you're signed in, in a narrow window and a wide one, blurred except for the school's logo and the Settings button. `portalInstructions(page)` builds the instructions the QR step shows. `portalScreenshots`, from `@-/me.unduo.components.setup.portal/server`, writes the screenshots' captions and pinned URLs into two `<template>`s: `#portal-signed-in`, which `portalStep` copies, and `#portal-screenshot-figures`, which `portalInstructions` copies; the build checks their URLs and pins, so they stay in the page's HTML. The link calls the setup page's `popup` to open the portal in a small window beside the steps, and `#portal-url` shows the same link with a Copy button for pasting into a new window. The instructions accept an `imageUrls` record and show the screenshots in a `<details>` element.
