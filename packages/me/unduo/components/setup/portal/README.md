# @-/me.unduo.components.setup.portal

Duo device portal guidance and example enrollment screenshots. `portalStep(school, page)` builds the step with the institution's portal link, note and source, which the page's `#setup` element holds as data attributes, then "Press **Continue** when you see a page like this:" over two examples of Duo once you're signed in, in a narrow window and a wide one, with only the device's name and number blurred. `authenticateStep(school, page)` builds the next step: authenticate with Duo as usual, with a passcode or a push, and press **Continue** on the My Settings & Devices page, shown with only the devices' names and numbers blurred. `portalInstructions(school, page)` builds the instructions the QR step shows: Tablet → Android → I have Duo Mobile installed. When `school.duoPrompt` is `universal` (the `#setup` element's `data-duo-prompt`), both steps name the Universal Prompt's labels instead: the page with **Add a device**, then Add a device → Duo Mobile → I have a tablet → Next. `portalScreenshots(image, set)` picks one of three sets: `traditional`, UofT's, with its logo and two signed-in examples; `generic`, the same with the logo painted out, for the file that names no institution; and `universal`, Waterloo's (from its IT knowledge base, with its logo), with one signed-in example because Duo's prompt looks the same in any window. `portalScreenshots`, from `@-/me.unduo.components.setup.portal/server`, writes the screenshots' captions and pinned URLs into three `<template>`s: `#portal-signed-in`, which `portalStep` copies, `#portal-settings`, which `authenticateStep` copies, and `#portal-screenshot-figures`, which `portalInstructions` copies; the build checks their URLs and pins, so they stay in the page's HTML. The link calls the setup page's `popup` to open the portal in a small window beside the steps, and `#portal-url` shows the same link with a Copy button for pasting into a new window. The instructions accept an `imageUrls` record and show the screenshots in a `<details>` element.
